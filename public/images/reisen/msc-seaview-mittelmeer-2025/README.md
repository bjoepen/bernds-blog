# Bilder der MSC-Seaview-Mittelmeerreise

## Ordner

```text
tag-01/ bis tag-08/   Bilder der einzelnen Reisetage
haefen/               Bilder für die Hafenbeiträge
schiff/               Bilder für den Schiffsbeitrag
reise/                übergreifende Bilder der Reise
```

In jedem Ordner kann eine Datei `hero.jpg` als Hero-Bild verwendet werden.
