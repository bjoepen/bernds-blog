# Northern Lines Design System

Northern Lines ist die gemeinsame visuelle und redaktionelle Sprache von Bernds Blog.

## Leitgedanke
> Nicht mehr Funktionen. Mehr Atmosphäre.

## Grundsätze
1. Ruhe vor Effekten.
2. Weißraum ist Teil des Inhalts.
3. Bilder erzählen.
4. Jede Komponente braucht eine klare Aufgabe.
5. Eine Reise wird erzählt, nicht nur protokolliert.
6. Chronologie ist optional.
