# Northern-Lines-Komponenten

Neue Magazin-Komponenten verwenden den Präfix `NL`:

```text
NLHero.astro
NLSectionDivider.astro
NLQuote.astro
```

Der Präfix kennzeichnet Komponenten, die unmittelbar zum Northern-Lines-
Designsystem gehören.

Bestehende Komponenten bleiben zur Wahrung der Kompatibilität unverändert.
