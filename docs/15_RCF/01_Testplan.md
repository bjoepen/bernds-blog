# RCF-Testplan

## Installation

- `npm run setup`
- `npm run verify`
- `npm run build`
- `npm run preview`

## Geräte

- Desktop ab 1440 px
- Notebook um 1280 px
- Tablet Hoch- und Querformat
- Smartphone um 390 px Breite

## Seiten

- Startseite
- Reiseübersicht MSC Seaview
- Reisetag 1
- Design-Hub
- Icon Library
- Hero Collection
- Editorial Foundations
- Impressum
- Datenschutz

## Prüfpunkte

- Navigation auf allen Geräten
- kein horizontales Scrollen
- Hero-Beschnitt
- Lightbox und Galerien
- Alt-Texte
- Tastaturbedienung
- sichtbare Fokuszustände
- interne Links
- Open-Graph-Bilder
- keine `.DS_Store`
- keine lokalen oder internen Pfade
