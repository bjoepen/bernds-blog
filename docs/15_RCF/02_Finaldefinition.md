# Definition von Final 1.4.0

Final ist erreicht, wenn:

1. `npm run verify` ohne Fehler durchläuft.
2. Der Produktions-Build erfolgreich erstellt wird.
3. Startseite, Reiseübersicht und Reisetag auf Desktop und Smartphone geprüft sind.
4. Mobile Navigation, Lightbox und alle sichtbaren Links funktionieren.
5. Keine kritischen Layoutverschiebungen oder überlappenden Texte vorhanden sind.
6. Hero Collection und Icon Library vollständig eingebunden sind.
7. Keine neuen Funktionen mehr für Final erforderlich sind.

Leitgedanke:

> Northern Lines soll Erinnerungen nicht nur dokumentieren, sondern wieder erlebbar machen.
