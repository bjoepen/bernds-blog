# RC5.2 – Responsive Navigation

RC5.2 führt eine zugängliche mobile Hauptnavigation ein. Sie basiert auf
dem nativen HTML-Element `<details>` und benötigt deshalb kein JavaScript.

## Breakpoints

- über 820 Pixel: vollständige Desktop-Navigation
- bis 820 Pixel: Menütaste und ausklappbare Navigation
- bis 390 Pixel: die lange Unterzeile des Logos wird ausgeblendet

## Editorial-Symbole

Die leicht versetzte Position bleibt als bewusste redaktionelle Gestaltung
erhalten. Der Abstand zur Überschrift wurde jedoch verkleinert und für
Mobilgeräte gesondert abgestimmt.
