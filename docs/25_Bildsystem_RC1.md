# Bildsystem im Release Candidate

## Inhaltsbilder

Normale Bilder in Beiträgen verwenden ihre natürliche Höhe, werden aber nie breiter als der Inhaltsbereich.

## Hero-Bilder

Empfohlen:

```text
1800 × 900 Pixel
Seitenverhältnis 2:1
```

Das Theme zeigt Hero-Bilder einheitlich und beschneidet sie bei Bedarf mit `object-fit: cover`.

## Galeriebilder

Empfohlen:

```text
1800 × 1200 Pixel
Seitenverhältnis 3:2
```

## Schutz besonderer Bilder

Logo, Favicon, Kartenmarker und SVG-Illustrationen werden von den allgemeinen Inhaltsbildregeln nicht verzerrt.
