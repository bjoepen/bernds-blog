# Navigation der Reise

## Reiseübersicht

Die Übersichtsseite erzeugt automatisch eine chronologische Liste aller zugehörigen Reisetage.

## Tagesseiten

Am Ende jeder Tagesseite erscheinen:

```text
Vorheriger Reisetag
Zur Reiseübersicht
Nächster Reisetag
```

## Entwürfe

Im Entwicklungsmodus werden Entwürfe angezeigt.

Im Produktions-Build werden nur Reisetage mit:

```yaml
draft: false
```

veröffentlicht.
