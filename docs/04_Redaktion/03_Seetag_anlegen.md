# Seetag anlegen

## Ziel

Einen Seetag als vollwertigen Reiseabschnitt behandeln.

## Content Type

```text
seetag
```

## Typische Kapitel

```markdown
## Der Morgen auf See
## Das Leben an Bord
## Fotografieren auf See
## 💙 Der Moment des Tages
## 💡 Unser Tipp
## 📖 Bernds Notizbuch
## Mit etwas Abstand
```

Ein Seetag ist kein Lückenfüller, sondern Teil der Reisegeschichte.
