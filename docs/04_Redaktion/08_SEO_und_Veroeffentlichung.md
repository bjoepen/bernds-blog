# SEO und Veröffentlichung

## SEO-Felder

```yaml
seoTitle: ""
seoDescription: ""
ogImage: ""
canonical: ""
```

## Veröffentlichung

1. Entwurfsstatus prüfen.
2. `draft: false` setzen.
3. Lokale Vorschau kontrollieren.
4. `npm run build` ausführen.
5. Inhalt von `dist/` auf den Server kopieren.

Nicht die Markdown-Dateien auf den Server kopieren.
