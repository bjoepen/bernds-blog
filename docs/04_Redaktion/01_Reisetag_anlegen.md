# Reisetag in Front Matter anlegen

## Ziel

Eine vollständige Tagesseite mit vorbereiteter Struktur anlegen.

## Voraussetzungen

- VS Code ist geöffnet.
- Front Matter ist installiert.
- `npm run dev` läuft.
- Das Projekt befindet sich lokal auf dem Mac.

## Schritt für Schritt

1. Front Matter öffnen.
2. Bereich **Reisetage** auswählen.
3. **New Content** anklicken.
4. Content Type **reisetag** wählen.
5. Dateinamen vergeben.

Empfohlen:

```text
msc-seaview-tag-01-anreise-einschiffung.md
```

## Pflichtfelder

- Titel
- Beschreibung
- Reisedatum
- Zugehörige Reise
- Tag
- Ort
- Art des Tages

## Tagesarten

```text
anreise
landgang
seetag
ausschiffung
```

## Vorschau

```text
http://localhost:4321/reisetage/DATEINAME/
```
