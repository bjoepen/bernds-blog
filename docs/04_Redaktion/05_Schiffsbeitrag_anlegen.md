# Schiffsbeitrag anlegen

## Ziel

Ein Schiff einmal beschreiben und später aus mehreren Reisen verlinken.

## Anlegen

```text
Front Matter → Schiffe → New Content → schiff
```

## Inhalte

- erster Eindruck
- Kabine
- öffentliche Bereiche
- Gastronomie
- Atmosphäre
- Stärken und Schwächen
- persönliches Fazit
