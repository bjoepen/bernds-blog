# Interne Verlinkung

RC3.3 verknüpft automatisch:

```text
Reiseübersicht
     ↓
Reisetag
     ↓
Hafenbeitrag
```

Jeder Reisetag erhält außerdem:

- vorheriger Reisetag
- nächster Reisetag
- Link zur Reiseübersicht

Die Verknüpfung erfolgt über:

```yaml
trip: "msc-seaview-mittelmeer-2025"
portSlug: "cannes"
```
