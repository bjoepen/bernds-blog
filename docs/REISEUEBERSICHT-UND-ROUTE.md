# Reiseübersicht und Routenkarte

Die erste Musterreise basiert auf der Mittelmeer-Kreuzfahrt mit der MSC Seaview vom 11. bis 18. Oktober 2025.

## Datei

```text
src/content/reisen/msc-seaview-mittelmeer-2025.md
```

## Route

Die Route wird im Front Matter unter `routeStops` gepflegt. Die Karte zeigt:

- nummerierte Marker
- Namen nur in der Liste oberhalb der Karte
- keine Detail-Popups
- eine gestrichelte Verbindung zwischen den Häfen
- Rückkehr zum Startpunkt, wenn beim ersten Eintrag `returnAtEnd: true` gesetzt ist

## Datenschutz

OpenStreetMap wird erst nach Klick auf den Ladebutton aufgerufen.
