# RC5.3 – Northern Lines Polish

RC5.3 verfeinert den bereits freigegebenen Aufbau, ohne ihn grundlegend zu
verändern.

## Schwerpunkte

- Editorial-Karten optisch ausbalanciert
- Symbole näher an die Überschriften gerückt
- Akzentstreifen in den Kartenrahmen integriert
- feinere Typografie und Leserythmus
- aktive Navigationspunkte
- Tastatur-Sprunglink zum Inhalt
- reduzierte Bewegung bei entsprechender Systemeinstellung
- Schutz vor horizontalem Überlauf auf Mobilgeräten
