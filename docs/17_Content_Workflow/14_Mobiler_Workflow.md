# Mobiler Northern-Lines-Workflow

## Unterwegs

1. `/admin/` öffnen.
2. Bei GitHub anmelden.
3. Reise oder Reisetag anlegen.
4. `draft: true` aktiviert lassen.
5. Text und Bilder erfassen.
6. Speichern; Sveltia schreibt einen Commit ins Repository.

## Zuhause

```bash
git pull
npm run verify
npm run dev
```

Danach:

- Text redaktionell überarbeiten
- Northern-Lines-Komponenten ergänzen
- Galerie kuratieren
- SEO prüfen
- `draft: false` erst zur Veröffentlichung setzen
