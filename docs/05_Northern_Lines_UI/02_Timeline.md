# Travel Timeline

Die Timeline eignet sich für:

- Reiseverläufe
- Tagesabläufe
- chronologische Rückblicke

Beispiel:

```mdx
<TravelTimeline
  title="Unser Tag"
  items={[
    {
      label: '09:00 Uhr',
      title: 'Ankunft',
      text: 'Erster Blick auf den Hafen.',
      icon: 'ship'
    },
    {
      label: '10:30 Uhr',
      title: 'Landgang',
      icon: 'marker'
    }
  ]}
/>
```
