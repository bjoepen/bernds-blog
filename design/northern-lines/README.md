# Northern Lines Symbol Library

Northern Lines ist das visuelle Symbolsystem von Bernds Blog.

## Stil

- Outline Silhouette Style
- nur Außenkonturen
- keine Füllflächen
- organische, ruhige Linien
- großzügiger Weißraum
- `currentColor` für flexible Einfärbung
